# 计算机应用基础 · 刷题练习

基于《计算机应用基础试题V1》整理的在线刷题网页，共 109 题：

- 选择题 96 道，点击选项立即判分
- 填空题 13 道，支持多种等价答案（如 `bit` / `二进制位`）
- 顺序练习、随机练习、按题型专练
- 错题自动收入错题本，可随时重练
- 答题卡跳题、练习结果统计与错题回顾
- 适配手机和电脑，支持键盘操作（A–D 选项，← → 翻题）

## 使用

直接打开 GitHub Pages 地址即可，所有答题记录保存在浏览器本地（localStorage），不会上传。

## 本地预览

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。
